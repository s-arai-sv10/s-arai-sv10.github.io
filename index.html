本アプリについて

本アプリ（zunda-uploader）は、運営者が自分の YouTube チャンネルを管理するためだけに使う個人用のツールです。運営者以外の利用者はいません。

利用する情報

本アプリは YouTube API Services を利用し、運営者の Google アカウントで許可された範囲で次の操作を行います。

  • 自分のチャンネルへの動画の投稿、サムネイルの設定、公開日時の設定
  • 自分のチャンネルと動画の情報（タイトル、再生回数など）の取得
  • 自分のチャンネルの分析データ（視聴時間、視聴維持率、流入元など）の取得

情報の保存と共有

取得した情報と認証情報は、運営者のパソコンの中にだけ保存します。第三者への提供、販売、広告への利用は行いません。

保存する情報と保存期間

運営者のパソコンには次のものを保存します。

  • Google の認証トークン（アクセスを取り消すか、不要になるまで）
  • 投稿した動画の ID と公開日時の記録（二重投稿を防ぐため。動画を削除したら記録も消します）
  • 分析のために取得したデータ（確認が終わり、不要になったら削除します）

Cookie や解析ツールは使っていません。

情報の削除

アクセス許可を取り消した場合、運営者は保存している認証トークンと API から取得したデータを7日以内に削除します。削除の依頼は、下のお問い合わせ先にメールで送ってください。7日以内に対応します。

アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントの設定ページ（https://myaccount.google.com/permissions）からいつでも取り消せます。

About this app

zunda-uploader is a personal tool used only by its operator to manage the operator's own YouTube channels. There are no other users.

Data we access

Using YouTube API Services, within the permissions granted by the operator's Google account, this app:

  • uploads videos, sets thumbnails, and schedules publishing on the operator's own channels
  • reads channel and video information (titles, view counts, etc.)
  • reads the operator's own channel analytics (watch time, audience retention, traffic sources, etc.)

Storage and sharing

All retrieved data and credentials are stored only on the operator's local computer. Data is never shared with, sold to, or used for advertising by any third party.

Data retention

The following is stored on the operator's local computer:

  • Google OAuth tokens (until access is revoked or no longer needed)
  • A record of uploaded video IDs and publish times (to prevent duplicate uploads; removed when the video is deleted)
  • Analytics data retrieved for review (deleted once no longer needed)

This app does not use cookies or tracking tools.

Data deletion

If access is revoked, the operator deletes the stored tokens and all data obtained from the API within 7 days. Deletion requests can be sent by email to the contact address below and will be handled within 7 days.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
